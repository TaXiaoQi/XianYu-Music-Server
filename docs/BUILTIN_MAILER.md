# 内置邮箱机使用说明

内置邮箱机是服务端统一邮件发送模块，用于注册验证码、找回密码验证码和后台测试邮件。推荐使用 `builtin` 模式，由服务端统一记录发送日志，并通过已配置的 SMTP 出口投递邮件。

## 发送模式

| 模式 | 配置值 | 说明 |
|------|--------|------|
| 内置邮箱机 | `builtin` | 服务端接收邮件请求、记录发送日志，按发件邮箱域名自动识别 SMTP 地址与端口，支持多账号轮流发送，失败后可回退外部 API |
| 外部 HTTP API | `http_api` | 直接调用外部邮箱机 API，适合作为备用通道 |

> 早期版本中的独立「标准 SMTP」模式已并入内置邮箱机：内置邮箱机本身就是基于 SMTP 投递，并额外提供日志、账号池轮换和失败回退，二者不再作为独立选项。服务端仍兼容 `smtp` 配置值。

## 自动识别 SMTP

内置邮箱机会根据发件邮箱的域名自动识别 SMTP 服务器地址和端口，无需手动填写。常见域名映射如下，未列出的域名回退为 `smtp.<域名>:465`：

| 域名 | SMTP 服务器 | 端口 |
|------|-------------|------|
| `qq.com` / `vip.qq.com` / `foxmail.com` | `smtp.qq.com` | `465` |
| `exmail.qq.com` | `smtp.exmail.qq.com` | `465` |
| `163.com` / `126.com` / `yeah.net` / `188.com` | 对应 `smtp.163.com` 等 | `465` |
| `gmail.com` | `smtp.gmail.com` | `465` |
| `outlook.com` / `hotmail.com` / `live.com` | `smtp.office365.com` | `587` |
| `yandex.com` / `zoho.com` 等 | 对应服务商 | `465` |

如遇特殊企业邮箱需要自定义地址，可直接在数据库 `server_settings` 的 `smtp_host` / `smtp_port` 中配置，服务端会优先使用显式配置。

## 内置模式流程

```text
注册 / 找回密码 / 测试邮件
↓
服务端内置邮箱机
↓
写入 email_send_log
↓
优先使用 SMTP 出口发送
↓
SMTP 未配置或发送失败时，回退外部 HTTP API
↓
更新发送结果和失败原因
```

内置邮箱机不是完整的互联网邮件服务器，它负责统一接入、日志记录和通道选择。实际邮件投递仍依赖 SMTP 服务商或外部 HTTP 邮件 API。

## 后台配置

进入后台：

```text
系统管理 -> 邮箱机设置
```

推荐配置方式：

1. 发送方式选择「内置邮箱机」。
2. 在「通用配置」中填写发件邮箱和邮箱授权码。
3. 「SMTP 投递」中的服务器地址与端口会自动识别，无需填写；只需确认 SMTP 授权码（留空则使用通用授权码）。
4. 如需多邮箱轮流发送，在「SMTP 账号池」中添加多个发件邮箱，每个账号只需填写发件邮箱、授权码和备注。
5. 如需备用通道，再填写「外部 API 备选」。
6. 保存配置后，在页面底部发送测试邮件。

测试邮件发送成功后，注册验证码和找回密码验证码会使用同一套发送入口。

## SMTP 配置字段

| 字段 | 示例 | 说明 |
|------|------|------|
| SMTP 服务器地址 | `smtp.qq.com` | 邮箱服务商提供的 SMTP 地址 |
| SMTP 端口 | `465` | 推荐使用 `465`，部分服务商也支持 `587` |
| SMTP 用户名 | `no-reply@example.com` | 通常与发件邮箱一致 |
| SMTP 密码 / 授权码 | `邮箱授权码` | 使用邮箱后台生成的授权码，不建议填写网页登录密码 |

端口 `465` 通常使用隐式 SSL/TLS；端口 `587` 通常使用 STARTTLS。国内常见邮箱一般要求先在邮箱设置中开启 SMTP 服务，再生成授权码。

## SMTP 账号池

内置邮箱机支持配置多个 SMTP 发件账号。账号池启用后，系统会根据 `email_send_log` 中内置邮箱机的发送次数选择下一个可用账号，实现轮流发送，降低单个邮箱被服务商风控或封禁的概率。

账号池中每个账号包含以下字段：

| 字段 | 说明 |
|------|------|
| 发件邮箱 | 邮件头中的 From 地址，同时用于自动识别 SMTP 服务器 |
| SMTP 服务器地址 | 自动识别，无需填写 |
| SMTP 端口 | 自动识别，无需填写 |
| SMTP 用户名 | 留空则使用发件邮箱 |
| SMTP 密码 / 授权码 | 邮箱后台生成的授权码或应用专用密码 |
| 启用 | 关闭后该账号不会参与轮换 |
| 备注 | 便于后台区分账号，例如「QQ 一号」 |

账号池为空时，内置邮箱机会继续使用上方的单 SMTP 出口配置。某个 SMTP 账号发送失败时，系统会继续尝试下一个可用账号；账号池内所有启用账号都失败后，才会尝试回退外部 HTTP API。如果外部 API 也未配置，本次邮件发送失败并写入日志。

账号池示例：

```text
账号 1：
发件邮箱：notice01@qq.com
SMTP 服务器地址：smtp.qq.com
SMTP 端口：465
SMTP 用户名：notice01@qq.com
SMTP 密码 / 授权码：QQ 邮箱授权码
启用：是

账号 2：
发件邮箱：notice02@163.com
SMTP 服务器地址：smtp.163.com
SMTP 端口：465
SMTP 用户名：notice02@163.com
SMTP 密码 / 授权码：163 客户端授权码
启用：是
```

## 常见服务商参数

| 服务商 | SMTP 服务器 | 端口 | 用户名 | 密码填写 |
|--------|-------------|------|--------|----------|
| QQ 邮箱 | `smtp.qq.com` | `465` 或 `587` | 完整 QQ 邮箱地址 | QQ 邮箱授权码 |
| 163 邮箱 | `smtp.163.com` | `465` 或 `994` | 完整 163 邮箱地址 | 163 客户端授权码 |
| Outlook / Hotmail | `smtp.office365.com` | `587` | 完整 Outlook 邮箱地址 | 账户密码或应用专用密码 |
| Gmail | `smtp.gmail.com` | `465` 或 `587` | 完整 Gmail 地址 | Google 应用专用密码 |

如果服务商开启了登录保护、二次验证或安全策略，请优先使用「应用专用密码」或「SMTP 授权码」。不要把邮箱网页登录密码直接写入生产环境配置。

## 外部 API 备选

外部 API 备选只在以下情况使用：

- 发送方式选择「外部 HTTP API」
- 发送方式选择「内置邮箱机」，但 SMTP 出口未配置或投递失败

通用参数格式：

```text
email=发件邮箱
password=调用密码或授权码
title=邮件标题
context=邮件正文
recipient=收件邮箱
```

外部 API 地址不要写死到前端或公开文档中，生产环境建议在后台或服务端配置中维护。

## 配置项

| 配置项 | 说明 |
|--------|------|
| `email_provider` | 邮件发送方式，推荐 `builtin` |
| `email_sender` | 发件邮箱地址 |
| `email_password` | 通用密码或授权码 |
| `smtp_host` | SMTP 服务器地址 |
| `smtp_port` | SMTP 端口 |
| `smtp_username` | SMTP 用户名 |
| `smtp_password` | SMTP 密码或授权码，留空时回退 `email_password` |
| `smtp_accounts` | SMTP 账号池 JSON，内置邮箱机用于多账号轮换发送 |
| `email_api_primary` | 外部 API 主地址 |
| `email_api_backup` | 外部 API 备用地址 |

## 测试与排错

保存邮箱机配置后，先在后台发送一封测试邮件到常用邮箱。测试成功后，再验证注册验证码和找回密码验证码。

常见问题：

- 认证失败：检查 SMTP 用户名是否为完整邮箱地址，密码是否为授权码或应用专用密码。
- 连接超时：检查服务器网络、SMTP 端口是否被防火墙拦截，必要时切换 `465` 和 `587` 测试。
- 收不到邮件：检查垃圾箱、服务商发信频率限制和发件邮箱是否被风控。
- 日志显示回退外部 API：说明 SMTP 出口未配置完整，或 SMTP 投递失败。
- 多账号未轮换：检查「SMTP 账号池」中是否有多个已启用且字段完整的账号。

发送失败时可查看 `email_send_log` 中的发送状态、失败原因和回退结果。

## 安全建议

- 授权码只保存在后台或服务端配置中，不要写入前端代码。
- 更换邮箱授权码后，需要同步更新后台邮箱机配置。
- 生产环境建议使用专门的发件邮箱，例如 `no-reply@your-domain.com`。
- 如果同一邮箱频繁触发服务商限制，可以改用企业邮箱或专业邮件服务商。
